# 炸弹克星 · 网页联机版

根据合作推理桌游《炸弹克星》(Bomb Busters) 制作的非官方网页版。2–5 人可以联机，也可以和 AI 队友单人练习。共 66 关，从新兵训练到终极炸弹。

- **完整规则**：打开页面后点「游戏规则」，包括配件、准备、各种剪线动作、12 张装备卡、特殊规则、沟通规则和推理技巧。
- **66 关**：前 8 关逐步教会全部规则，之后每关加入新变化（读秒、浓雾、顺序引信、缺失数值、禁止聊天……）。
- **AI 队友**：AI 只使用自己能看到的信息，用蒙特卡洛采样推算每根线的概率，可以补足人数或陪你练习。

> 实体版的 66 关任务装在密封的惊喜盒里，内容不公开。这里的 66 关是按照“逐步引入规则、难度递增”的思路重新设计的，与官方任务并不相同。

## 怎么和朋友一起玩

### 方式一：自建服务器（任何人打开网址就能玩）

需要 Node.js 18 以上：

```bash
npm install
npm start          # 默认端口 8080，可用 PORT=xxxx 修改
```

打开 `http://localhost:8080`。局域网内的朋友访问 `http://你的电脑IP:8080`。

想让外地的朋友也能玩，把它部署到任意支持 Node 的平台（Render、Railway、Fly.io 等）：构建命令 `npm install`，启动命令 `npm start`。服务器只负责转发消息，几乎不占资源。也可以用 `cloudflared tunnel --url http://localhost:8080` 临时生成一个公网地址。

### 方式二：claude.ai Artifact

本页面也可以作为 claude.ai Artifact 运行，联机走 Artifact 自带的实时房间。好友需要被分享该页面，并拥有「可互动」或更高权限。

### 开一局

1. 一人点「创建联机房间」，把 4 位房间码发给朋友。
2. 朋友输入代号和房间码加入。房主可以加 AI 队友补位，然后选关、开始。
3. 掉线了？用同一个浏览器重新打开，点「重新进入」即可回到原座位。房主刷新后也能恢复牌局。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面、样式、规则说明 |
| `js/engine.js` | 规则引擎（纯数据，房主权威） |
| `js/missions.js` | 66 关任务表 |
| `js/bot.js` | AI 队友 |
| `js/net.js` | 联机传输层（Artifact 房间 / WebSocket） |
| `js/app.js` | 界面与联机流程 |
| `server/server.js` | 静态页面 + WebSocket 房间中继 |
| `test/` | 规则单元测试和全关卡模拟 |

```bash
node test/rules.test.js     # 规则单元测试
N=4 node test/sim.js        # 让 AI 把 66 关 × 2–5 人各打 N 局，检查有没有卡死或报错
```

规则由房主的浏览器运行，每人的手牌通过房间转发给本人。这是合作游戏，技术上可以在开发者工具里偷看数据，但偷看只会让游戏变无聊。

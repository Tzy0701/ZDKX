## 额外角色和装备

个人能力有：双重探测器、三重探测器、X/Y 射线、通用雷达、对讲机。每人每任务一次，不需要编号解锁，与同名共享装备独立；备用电池可以恢复已用角色。

| 共享装备 | 解锁 | 功能 |
| --- | --- | --- |
| 双层底盒 | 首两根黄线 | 添加两张随机未入局装备；按已剪线重新判断是否可用 |
| 单一导线标签 | 四根蓝 2 | 自己某蓝值在此架只出现一次，计入已剪线；放 ×1 |
| 应急储备箱 | 四根蓝 3 | 恢复已用共享装备；与恢复角色的备用电池不同 |
| 单剪通行证 | 四根蓝 9 | 允许单拆自己两根同值，即使另两根仍未剪 |
| 分解器 | 四根蓝 10 | 随机蓝色信息标记指定值，处理全员该值剩余线 |
| 抓钩 | 四根蓝 11 | 把队友一根未剪线拿到自己任选一架并排序；取出/插入位置公开，值不公开 |

新卡名字在此为功能译名，不声称是某中文版的官方译名。法语分解器写全员剪，德语使用允许措辞；是否允许保留线仍需裁定。三张卡底的“即时效果”与“随时”不同，解锁后是否强制触发也列入待确认项，不能直接按推测写入引擎。

## 音频关的机制

| 关卡 | 已找到的主要机制 |
| --- | --- |
| 19 | 宣告的倒计时中途缩短；爆炸后录音继续，并不增加游戏时间 |
| 30 | 限时数字目标、达成奖惩、阶段禁语、三个数字的限制阶段、黄线紧急拆除和分支胜负 |
| 42 | 没有总时限；恢复已剪线、玩家换座保留线架、交换/移除已剪线、移除完成标记、声音与口令事件 |
| 54 | 十分钟、区域氧气费用、完成蓝值补氧、动态红线、连续行动、氧气转移、最后屏息阶段 |
| 66 | 开门、制服守卫、下楼、关闭黄色激光、重排限制、铐住博士、最后完成拆弹；每阶段单独期限及失败分支 |

JSON 的 `speechWindowSeconds` **仅定位语音片段**。自动转录会漏句、把音乐识别为文字或错配时间；这些窗口不能直接作为运行时信号音边界。录音要求信号音之间停止拆线听指令，因此不能把整段文件长度当成游戏倒计时。

## 本次纠正的研究记录

- 挑战 6 是至少五根**孤立**未剪线，相邻未剪线之间有已剪线；不是五根连续未剪线。
- 53 关机器人从数字 1 **之前**开始，而非从 1 开始。
- 64 关随机反转两根线，较小的放左端、较大的放右端；不是反转原手牌最小和最大值。两架仍总共两根。
- 35 关禁止对讲机也包括个人对讲机角色；34 关揭开原角色后不能重新挑角色。
- 66 关条纹格执行 ACTION 时，成功或失败均不移动；成功才执行特殊动作。

## 如何把剩余 48 关升级为已核实

1. 按 `mission-audit.json` 的逐关设置和本记录的组件规则建立独立任务模块，明确设置、合法动作、结算、信息可见性、回合转换及胜负。
2. 装备、角色、限制、数字牌和挑战使用稳定身份及独立状态；保留宣告 → 对方公开回应 → 行动者选择自己的同值线。
3. 实现频率/奇偶/X、特殊多目标拆线、朝外隐藏线、机器人、氧气和地图；不能用通用回合数或惩罚替代。
4. 单独核对五录音的全部信号和声音事件，结合分支、暂停、重连与服务器重启测试。
5. 每关按支持人数做来源导出的设置及机制验收。34、65 不支持两人；其他玩家数例外均按任务卡。
6. 每阶段提高内容版本；只有源码与验收通过的关卡才改为“已核实”。改编任务的通关不能认证新的实体实现。

还需明确：即时效果触发时机、分解器版别措辞、挑战 2/7 在批量拆线中的序列计数、精确音频信号。所有这些均已记录来源，不用虚构规则填空。
